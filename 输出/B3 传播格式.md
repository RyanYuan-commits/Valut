## 1	介绍

B3 传播格式是 Zipkin 分布式追踪系统中用于传递追踪信息的标准协议。它定义了 HTTP 请求头或消息协议（如gRPC）中如何编码和传递追踪上下文，确保跨服务的调用链能够正确关联。B3 格式最初由 Zipkin 团队提出，现已成为业界广泛采用的传播标准之一。

B3的名称来源于 BigBrotherBird（灵感来自《1984》中的监控隐喻），其核心是通过一组特定的HTTP头字段传递以下信息：

| 名称             | 含义              |
| -------------- | --------------- |
| trace_id       | 全局唯一的追踪标识符      |
| span_id        | 当前操作的唯一标识符      |
| parent_span_id | 父级操作的标识符（可选）    |
| sampled        | 采样标志，决定是否记录追踪数据 |

## 2	B3 头字段

B3 格式支持单头模式和多头模式两个变体。单头模式下，所有的信息合并为一个头字段；多头模式下则拆分为多个独立头字段。

单头模式格式为：`b3: {TraceId}-{SpanId}-{SamplingDecision}-{ParentSpanId}`，如：

```plaintext
b3: 80f198ee56343ba864fe8b2a57d3eff7-e457b5a2e4d86bd1-1-05e3ac9a4f6e3b90
```

多头模式示例如下：

```plaintext
X-B3-TraceId: 80f198ee56343ba864fe8b2a57d3eff7
X-B3-SpanId: e457b5a2e4d86bd1
X-B3-ParentSpanId: 05e3ac9a4f6e3b90
X-B3-Sampled: 1
```
