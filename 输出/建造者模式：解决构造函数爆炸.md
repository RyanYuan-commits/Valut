## 1	使用场景

当一个类包含几个必填属性，同时有包含大量的可选属性时，此时为了应对不同的实例化需求，需要==大量的重载构造函数==，此时可以使用 builder 实现，

要求对象具有==不可变性==，此时需要去掉所有的 setter 方法，要求在构造方法中完成所有属性的赋值，结果类似场景一；

当创建对象时，需要检查参数之间的逻辑关系来判断对象的合法性，如果全部写在类构造方法中，会导致职责不明确，此时可以将逻辑校验收拢在 builder 的 `build()` 方法中。

## 2	代码案例

```java
public class Main {  
  
    public static void main(String[] args) {  
        ComplexObject complexObject = new ComplexObject.Builder("1", "2")  
                .optParam1("1")  
                .optParam2("2")  
                .build();  
    }  
  
    public static class ComplexObject {  
  
        private final String reqParam1;  
        private final String reqParam2;  
  
        private final String optParam1;  
        private final String optParam2;  
  
        private ComplexObject(Builder builder) {  
            this.reqParam1 = builder.reqParam1;  
            this.reqParam2 = builder.reqParam2;  
  
            this.optParam1 = builder.optParam1;  
            this.optParam2 = builder.optParam2;  
        }  
  
        public String getOptParam1() {  
            return optParam1;  
        }  
  
        public String getOptParam2() {  
            return optParam2;  
        }  
  
        public String getReqParam1() {  
            return reqParam1;  
        }  
  
        public String getReqParam2() {  
            return reqParam2;  
        }  
  
        public static class Builder {  
  
            private final String reqParam1;  
            private final String reqParam2;  
  
            private String optParam1 = null;  
            private String optParam2 = "default";  
  
            public Builder(String reqParam1, String reqParam2) {  
                this.reqParam1 = reqParam1;  
                this.reqParam2 = reqParam2;  
            }  
  
            public Builder optParam1(String val) {  
                this.optParam1 = val;  
                return this;  
            }  
  
            public Builder optParam2(String val) {  
                this.optParam2 = val;  
                return this;  
            }  
  
            public ComplexObject build() {  
                if (optParam2 == null || optParam2.isBlank()) {  
                    throw new IllegalArgumentException("optParma2 can not be empty");  
                }  
                return new ComplexObject(this);  
            }  
  
        }  
  
    }  
  
}
```
