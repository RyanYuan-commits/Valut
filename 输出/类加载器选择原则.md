如果在写框架，需要加载用户编写的类，使用线程上下文类加载器，通过 `Thread.currentThread().getContextClassLoader()`；若没有特殊设置，线程上下文类加载器和系统主线程的类加载器相同；

如果想读取和当前代码打包在一起的配置文件，或者显式加载一个和你同属一个工程/JAR 包里的类，使用当前类的类加载器；因为要加载的资源和当前类处在同一 jar 包中，有加载当前类的能力的类加载器一定也有能力加载这些资源；

不要信任单一的类加载器，做好兜底：

```java
ClassLoader cl = Thread.currentThread().getContextClassLoader();
if (cl == null) cl = MyCurrentClass.class.getClassLoader();
if (cl == null) cl = ClassLoader.getSystemClassLoader();
```
