**关键词**: 计算属性, Vue

---

```js
const publishedBooksMessage = computed(() => {
  return author.books.length > 0 ? 'Yes' : 'No'
})
```

## 1	使用场景

实现一个展示用户有没有发布过的书籍的功能, 这样的模板看起来很复杂, 且整个项目中可能不止一次需要这样的模板, Vue 提供了计算属性来处理这种情况: 计算属性使用 `computed()` API 定义; 其接收一个 getter 函数, 返回值是一个计算属性 ref, 和其他的 ref 类似, 可以通过 `.value` 访问计算结果.

```vue
<script setup>
const author = reactive({
  name: 'John Doe',
  books: [
    'Vue 2 - Advanced Guide',
    'Vue 3 - Basic Guide',
    'Vue 4 - The Mystery'
  ]
})

const publishedBooksMessage = computed(() => {
  return author.books.length > 0 ? 'Yes' : 'No'
})
</script>

<template>
<p>Has published books:</p>
<span>{{ author.books.length > 0 ? 'Yes' : 'No' }}</span>
<span>{{ publishedBooksMessage }}</span>
</template>
```

## 2	计算属性

### 2.1	计算属性缓存 vs 方法

如果将同样的函数定义为方法而不是计算属性, 效果看起来是相同的, 但是计算属性会**基于其响应式的依赖**进行更新, 一个计算属性不管被访问多少次, 只要其依赖的响应式数据没有发生变化, 计算就不会重复进行, 而方法总是会在重渲染时执行函数. 这也解释了为什么下面的属性永远不会更新, 因为 `Date.now()` 不是一个响应式的依赖:

```js
const now = computed(() => Date.now())
```

### 2.2	获取上一个值

可以通过访问计算属性的 `getter` 的第一个参数来获取计算属性返回的上一个值:

```vue
<script setup>
import { ref, computed } from 'vue'

const count = ref(2)

const alwaysSmall = computed((previous) => {
  if (count.value <= 3) {
    return count.value
  }

  return previous
})
</script>
```
